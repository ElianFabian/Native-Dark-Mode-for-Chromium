# Release screenshots

`popup.png` and `rule-manager.png` are the original PNG screenshots supplied by the project owner for 0.9.0 on 2026-11-11. Both English and Spanish READMEs use these same files. They show the English interface; the popup selects Simulated Native and the manager shows Rule defaults and the four website themes.

The screenshots illustrate UI state, not a guarantee of rendering quality on every website. They were copied without rescaling or AI editing. Future screenshots should use public/sample rules and avoid private account details.
